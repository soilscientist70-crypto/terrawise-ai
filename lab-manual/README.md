# TerraWise Soil Laboratory Manual

A browser-based reference covering soil physical, chemical and biological methods, plant tissue analysis, and water analysis. Browse the catalog, search method names or analytes, open a starter panel, save a local shortlist, and export the shortlist as CSV.

Open `index.html` alongside `styles.css`, `methods.js`, and `manual.js`. Source citations need internet access. The shortlist uses browser storage where available. No account or server is required.

The initial public edition was compiled in November 2026. Entries contain original summaries and link to their sources. Consult the specified source edition and the lab’s controlled SOP for execution. Published procedures are distinct from local method validation, regulatory acceptance, and method-specific accreditation.

To add a method, use a unique ID and include the matrix, method and source, specimen, equipment, reporting basis, principle, quality checks, and limitations. Update the starter panel when relevant. Link to the publisher or responsible public laboratory and indicate catalog access when the full procedure is paywalled.

## FAO field methods

The FAO field screening panel contains 16 original method-selection summaries with printed page references from [FAO, 2020, Soil Testing Methods – Global Soil Doctors Programme](https://doi.org/10.4060/ca2796en). The source publication is licensed CC BY-NC-SA 3.0 IGO. Follow the publisher’s terms for reuse of the source material. The panel distinguishes preliminary field observations from validated laboratory procedures.
