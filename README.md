# TerraWise AI

A soil characterization demo with USDA texture, sieve gradation, Atterberg limits and preliminary inorganic USCS screening. The sample data are synthetic. Calculations and CSV imports run in the browser.

- [Live demo](https://soilscientist70-crypto.github.io/terrawise-ai/)
- [Offline demo](TerraWise-AI.html)
- [Source, sample data and tests](TerraWise-AI-source.zip)

The optional model draft requires the local server and an installed Ollama model. USCS screening requires qualified review before engineering use.
